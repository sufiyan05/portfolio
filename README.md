# Sufiyan Sitponiya - Portfolio Website

A premium, modern, animated portfolio website showcasing my work as a Native Mobile Application Developer specializing in iOS and Android development.

## 🚀 Features

- **Premium Dark Theme** - Modern, elegant design with glassmorphism effects
- **Smooth Animations** - 60 FPS animations including fade-in, slide-up, parallax, and hover effects
- **Fully Responsive** - Optimized for desktop, laptop, tablet, and mobile devices
- **SEO Optimized** - Complete meta tags, Open Graph, Twitter Cards, and structured data
- **Accessible** - ARIA labels, keyboard navigation, and semantic HTML
- **Performance Optimized** - Lightweight vanilla JavaScript, no build tools required
- **Interactive Elements** - Cursor glow, scroll progress, smooth scrolling, and form validation

## 🛠️ Tech Stack

- **HTML5** - Semantic markup with complete SEO structure
- **CSS3** - Modern CSS with custom properties, animations, and responsive design
- **Vanilla JavaScript** - No frameworks, pure JS for optimal performance

## 🚀 Getting Started

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/sufiyan05/portfolio.git
cd portfolio
```

2. Open `index.html` in your browser:
```bash
# On macOS
open index.html

# On Windows
start index.html

# On Linux
xdg-open index.html
```

3. Or use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (with http-server)
npx http-server
```

Then visit `http://localhost:8000` in your browser.

### Deployment

This project is designed for GitHub Pages deployment:

1. Push to GitHub repository
2. Enable GitHub Pages in repository settings
3. Select main branch as source
4. Your site will be live at `https://username.github.io/repository-name/`

## 🔧 Customization

### Updating Personal Information

Edit `index.html` to update:
- Name and title in Hero section
- About section content
- Skills and technologies
- Experience timeline
- Project details
- Contact information
- Social media links

### Modifying Colors

Edit CSS variables in `css/style.css`:
```css
:root {
    --bg-primary: #0a0a0f;
    --bg-secondary: #12121a;
    --accent-primary: #6366f1;
    --accent-secondary: #8b5cf6;
    /* ... more variables */
}
```

### Adding Projects

Add new project cards in the Projects section of `index.html`:
```html
<div class="project-card reveal">
    <div class="project-image">
        <!-- Add your project image -->
    </div>
    <div class="project-content">
        <h3>Your Project Title</h3>
        <p>Project description</p>
        <div class="project-tech">
            <span>Tech1</span>
            <span>Tech2</span>
        </div>
        <div class="project-links">
            <a href="your-github-link" class="btn btn-small">GitHub</a>
            <a href="your-demo-link" class="btn btn-small btn-outline">Live Demo</a>
        </div>
    </div>
</div>
```
